# Native app (React Native)

The same design system on React Native. Everything on this page runs the **`.native.tsx`** implementations: `Pressable`, `TextInput` and `StyleSheet`, fed by the same `tokens.json` as the web components in the rest of this playground. The app code imports `Button` from `@mal/design-system` exactly as a web app does, and the bundler picks the platform file.

## What's shared and what isn't

| Shared once, both platforms | Per platform |
| --- | --- |
| `tokens.json` values and theme names | Styling: Tailwind classes (web) / `StyleSheet` (native) |
| `Name.types.ts` prop contracts and variant names | Primitives: `<button>`/`<input>` vs `Pressable`/`TextInput` |
| Zakat maths, validation, money formatting | Event names: `onClick` vs `onPress` |
| Screen-reader text ("Spent AED 64.50"), copy, icon geometry | Announcements: `aria-live` vs `accessibilityLiveRegion` / `announceForAccessibility` |

Source: `apps/mobile/App.tsx` in the repository.
