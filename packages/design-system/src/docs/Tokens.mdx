# Tokens

Tokens are authored once in **`tokens/tokens.json`** ([W3C DTCG format](https://tr.designtokens.org/format/), the format Figma Variables and Style Dictionary speak). `npm run tokens` compiles them for each platform:

- **Web:** `src/styles/theme.css`, a Tailwind `@theme` block (so each token *is* a utility class) plus `[data-theme]` scopes that remap colours at runtime.
- **React Native:** `src/tokens/tokens.generated.ts`, typed values with dimensions as px numbers, read through `useTheme()`.

**Tailwind's default palette and spacing scale are removed.** If a value isn't a Mal token, the class doesn't exist.
