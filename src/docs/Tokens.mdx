# Tokens

Tokens are authored once in `src/tokens/tokens.ts` and compiled by `npm run tokens` into `src/styles/tokens.css`:
a Tailwind `@theme` block (so each token *is* a utility class) plus `[data-theme]` scopes that remap colours at runtime.

**Tailwind's default palette and spacing scale are removed.** If a value isn't a Mal token, the class doesn't exist.
